🎯 操作方式

  • 选择/拖拽 (V)：点击物体选中，拖拽移动
  • 平移视图：按住空格 + 鼠标拖拽，或鼠标中键拖拽
  • 缩放：滚轮，或 + / - 键
  • 删除：按 Delete 键，或选择删除工具点击物体
  • 创建物体：点击左侧工具栏的物体类型，在画布上拖拽
  • 创建约束：先点击一个物体起点，拖拽到第二个物体释放
  • 右键菜单：在物体上右键可复制/删除/切换静态

🔧 快捷键

V 选择 / B 方块C 圆球 / R 斜面 P 平台 / S 弹簧H 杆 / K 绳索 空格 播放/暂停Esc 取消/选择 0 重置视图+ / - 缩放

📐 受力箭头说明

● G（重力）：竖直向下，G = mg

● N（支持力）：垂直于接触面，指向被支持物体

● f（摩擦力）：沿接触面，与相对滑动方向相反

● F弹（弹簧弹力）：沿弹簧方向，拉长时向内收缩

● T（约束力）：沿杆/绳索方向

● D（空气阻力）：与速度方向相反（默认关闭）

可在底部栏开关各类力的显示。

🎯 触控操作

  • 选择/拖拽：点击物体选中后拖拽移动
  • 平移视图：单指在空白处拖动
  • 缩放：双指捏合
  • 删除物体：点击底部「删除」工具，再点击物体
  • 创建物体：点击底部工具栏的物体类型，在画布上拖拽
  • 创建约束：先点击一个物体起点，拖拽到第二个物体释放
  • 长按菜单：长按物体弹出复制/删除/切换静态菜单
  • 属性面板：选中物体后点击底部「属性」按钮编辑参数
  • 设置面板：点击底部「设置」按钮调整重力/时间流速
